## Create and activate virtual environment
```bash
python3 -m venv .venv
source .venv/bin/activate
```

## Install project dependencies
```bash
pip install -r requirements.txt
```

## Run inference with ChatGPT-like GUI
```bash
streamlit run inference_gui.py
```
